API keys

This app uses Claude's vision API to read watch photos. This requires a paid Anthropic API key with billing enabled — usage is billed per request. Get a key at console.anthropic.com and add some credit.

When a reference number isn't legible, it's looked up via Gemini with Google Search — Gemini looks at the photo directly and grounds its answer in real Google results. Get a key at aistudio.google.com/apikey, and make sure billing is enabled on the linked Google Cloud project for reliable quota. Free for several thousand lookups/month, then a small per-lookup charge after that. Leave blank to skip lookup (no reference will be shown for unclear photos rather than a guess).

Both keys are stored only in this browser, never sent anywhere except directly to Anthropic's and Google's APIs.

Cross-device sync (optional): by default everything you analyze stays only on this device. To see the same stock/demand on your phone and your PC, fill in both pieces below and use the exact same values on every device you want synced. Leave both blank to keep this device-only.

1. Catalog data & images — both are stored in Supabase (Firebase not needed). Fill in Supabase URL, anon key, and Sync ID below.

2. Images (free, no card) — Firebase Storage now requires a paid plan, so images use Supabase instead. Create a free project at supabase.com, make a Storage bucket named exactly stockmatch-images (set it Public), then paste its Project URL and anon/public API key (both found in Project Settings → API).

3. Sync ID — any name you choose, used to keep your data separate from anyone else using the same Firebase/Supabase project.
